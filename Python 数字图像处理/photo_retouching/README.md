# photo_retouching 人像精修

**版本 1.0（基准，2026-11-16）**：人像精修 `main.py` + 自动校正 `auto.py`（建筑拉直、亮度、降噪、天空高光恢复）。
9 张实拍样片在 1.0 下的输出存于 `~/PycharmProjects/sample/基准_v1.0/`，审查总览图在 `~/PycharmProjects/sample/对比/`；
之后的改动都和这一版逐张对比。

OpenCV 人像精修流水线。CPU 上 1000×1500 的图约 2 秒（首次加载 mediapipe 另需 2~3 秒）；
6000×4000 的相机原片约 8~16 秒（皮肤类步骤只在人物周围的裁剪区做）。

三个可选模型，缺失时自动下载到 `models/`，不可用时自动降级：

| 模型 | 用途 | 降级方案 |
|---|---|---|
| mediapipe FaceLandmarker（478 点，3.7 MB） | 人脸定位、五官/鼻孔/眼袋位置、瘦脸推点 | OpenCV Haar 人脸框（`--no-landmarks`） |
| BiSeNet 人脸分割 ResNet18 ONNX（53 MB，[yakhyo/face-parsing](https://github.com/yakhyo/face-parsing)） | 像素级区分脸、鼻、耳、脖子、五官、头发、衣物 | 自适应肤色模型（`--no-parsing`） |
| mediapipe selfie_multiclass（16 MB） | 上半身范围区分头发、身体皮肤、脸、衣物，限制身体皮肤不漏到衣服上 | 只用肤色模型（`--no-parsing`） |

## 用法

```bash
pip install -r requirements.txt   # mediapipe、onnxruntime 可选

python main.py                          # 处理 data/raw/ 下所有图片，输出到 output/
python main.py photo.jpg                # 单张，输出 output/photo_retouched.jpg
python main.py photo.jpg --compare      # 额外输出前后对比图
python main.py photo.jpg --debug        # 质量检查：各阶段输出、蒙版、瑕疵分类、100% 局部对比 -> debug/photo/
python main.py data/raw --smooth 0.9 --freckles 0.5 --moles --slim 0.5
```

## 处理步骤

| 顺序 | 步骤 | 参数（默认） | 实现 |
|---|---|---|---|
| 0 | 人脸 + 蒙版 | `--no-landmarks` `--no-parsing` | 长边超过 2000 时分块检测人脸（广角环境人像脸太小，整图检测不到）；分割得到脸/脖子/耳朵皮肤和五官、头发保护区；胸口手臂等身体皮肤用脸部采样的肤色模型补充，须与脖子相连且落在人像分割的皮肤区内。没有人脸时跳过所有皮肤步骤 |
| 1 | 瑕疵分类修复 | `--blemish 1.0` `--freckles 0` `--moles` | 暗点（L 黑帽）+ 红点（a 顶帽）→ 按大小、明暗差、红度差分为痘/色斑/雀斑/痣；痘全修、色斑减淡 70%、雀斑和痣默认保留。修复用 inpaint 补低频 + 邻近干净皮肤的纹理。眼周、眉间、嘴角、鼻侧不检测；处于阴影/褶皱中的不算 |
| 2 | 色彩校正 | `--color 0.3` | 灰度世界白平衡 + 全局色阶 |
| 3 | 匀肤（色度） | `--even 0.5` | 只在 Lab 的 a/b 上做低频均衡：泛红、色斑、眼下发青 |
| 4 | Dodge & Burn | `--dodge-burn 0.6` `--eye 0.5` | 只改亮度 L：小幅明暗斑驳拉平，大幅的立体阴影（鼻梁、颧骨、下颌）保留；眼下单独提亮黑眼圈 |
| 5 | 多尺度磨皮 | `--smooth 0.7` `--grain 0.6` | 皮肤拆成高/中/低频，主要削弱中频（痘印、细褶皱）；高频按相机噪声收缩，颗粒去掉、毛孔保留；鼻子、身体削弱更少 |
| 6 | 美白 | `--whiten 0.2` | LAB 亮度对数曲线 |
| 7 | 锐化 | `--sharpen 0.5` | USM，只作用于非皮肤（眼、眉、发） |
| 8 | 瘦脸 | `--slim 0`（关闭） | 沿关键点下颌线两侧 5 对推点向鼻尖局部液化 |

强度设为 0 即关闭对应步骤。

## 自动校正（auto.py）

不做皮肤处理，人像、夜景、风景通用：建筑拉直 + 亮度校正 + 自适应降噪 + 天空高光恢复。6000×4000 约 7~10 秒。

```bash
python auto.py photo.jpg                  # 输出 output/photo_auto.jpg
python auto.py ~/PycharmProjects/sample --compare
python auto.py photo.jpg --debug          # debug/<图名>/gain.jpg（增益图）+ report.txt（分析与参数）
python auto.py photo.jpg --target 62 --denoise 0
python auto.py photo.jpg --keystone 1      # 透视完全拉直（默认 0.8）；--straighten 0 关闭
python auto.py photo.jpg --sky-darken 0.8  # 天空压得更暗（默认 0.6 档）；--sky 0 关闭
```

| 步骤 | 参数（默认） | 实现 |
|---|---|---|
| 拉直 `scripts/geometry.py` | `--straighten 1` `--keystone 0.8` | 主体 = 竖直长线最密的区域（建筑、窗框；树草天空几乎没有长直线）；主体内全分辨率取关键竖直边，加权求竖直消失点；用相机旋转 H = K·R·K⁻¹ 纠正：左右歪全额，仰拍上窄下宽按 80%（完全拉直楼顶显大）；焦距像素数取自 EXIF 焦平面分辨率。关键边少于 6 条、彼此不一致或角度过大时跳过。裁出原画幅比例的最大内接矩形 |
| 分析 `scripts/analyze.py` | — | EXIF（ISO、快门、光圈）、人脸、亮度分布、高光溢出、噪声（只在中间亮度区域估计；色度噪声在 4 像素尺度上量）、场景（人像/夜景/风景） |
| 亮度 `scripts/exposure.py` | `--exposure 1` `--target 58` | 对数域导向滤波取照明层，只对照明层做色调映射得到增益图，纹理不变。人像：脸部 L 低于目标才提亮，72 以上才压暗；提亮倍数还受脸部受光面限制（最亮通道 97 分位 ≤ 0.8），侧光时不会把亮面冲白。按每像素最亮通道做软肩，提亮后不新增溢出；极暗处（夜空）不提亮。最多 +2 档 |
| 天空 `scripts/sky.py` | `--sky 1` `--sky-darken 0.6` | 渐变滤镜 × 亮度范围蒙版（同 Lightroom 做法），不划天空边界：顶部到天空最低处的竖直渐变，乘以“越接近天空亮度越大”的权重，树枝、山体逐像素自动排除，树冠周围无亮圈、雾里无斑块。渐变减光 + 最亮通道软肩，接近溢出的云显出层次；三通道全溢出的像素补成周围天空的平滑渐变（不假装恢复细节）。天空没有云层次（阴天一片白）时不处理，压暗只会变灰 |
| 降噪 `scripts/denoise.py` | `--denoise 1` | 有效噪声 = 实测噪声 × 提亮增益；低于可见阈值直接跳过（相机 JPEG 通常如此）。色度用亮度导向的导向滤波去彩色斑点，亮度用自导向导向滤波并保留 30% 颗粒 |

拉直样片：IMG_5165 室内歪 0.72°、无透视，校正后复测 0.02°，保留 96% 面积；IMG_5193 碉楼歪 0.52°、仰拍 7.3°，
校正后复测歪 0.08°、剩余仰俯 1.27°（即 20%），保留 90% 面积；人像和风景照全部自动跳过。

天空样片：IMG_5703 导出图天空溢出 17.4% → 0%（其中 5.1% 三通道全溢出，补成平滑渐变），云层轮廓显出；
IMG_5798 天空压暗，被阳光照亮的小镇更突出；IMG_5193 阴天无云，自动不处理。

亮度样片结果（5 张夜景人像）：脸部 L 44/45/51/52/66 → 48/50/56/55/66，新增溢出 ≤ 0.07%；
噪声实测很低（机内已降噪），降噪全部自动跳过。5238、5239 是强侧光，受光面限制使提亮幅度较小。

## 局限

- 实拍样片 9 张（`~/PycharmProjects/sample`，Canon R10）：5 张夜景环境人像、2 张建筑、2 张风景；阈值仍需更多白天、近景原片验证。
- 1.0 已知问题：`auto.py` 对没有人脸的照片按全图亮度中位数定提亮倍数，太粗：阴天白天空的 5193、俯瞰的 5703 被压暗到 ×0.80 发灰，
  室内的 5165 被当成夜景提亮 ×1.50，5798 被提亮 ×1.49（与 Lightroom 修图方向相反）。
- 1.0 已知误检：5247 噘嘴时脸颊凹陷被当成色斑减淡；5239 整张拖影（应由废片检测标出）。
- 祛痘不检测眼周、眉间、嘴角、鼻侧，这些位置的痣和痘不会处理；浅雀斑基本检测不到。
- 内部各步仍是 8-bit，不支持 16-bit TIFF / ICC / RAW。
- 没有检出人脸时不做任何皮肤处理（只调色、锐化）；Haar 模式只认正脸，且在实拍上误检多。
